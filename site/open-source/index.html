Tacit Chassis

The open-source base that Mission Room forks are built from: a small core that holds the rules, ports for every vendor, and adapters that a fork chooses for one kind of work.

Status, 15 October 2026. In development.
  • Version 0.1 is not yet public, and no date is promised here.
  • The intended licence is Apache-2.0. The repository link will appear on this page at release.
  • Papers on this page describe designs. Each labels what is in the code, what is in current build scope and what is only proposed.

What it is

The working paper Tacit Work Needs a Mission Room argues for a bounded workspace in which agents draft and a named person confirms. Tacit Chassis is the implementation of that idea, written to be forked. A fork changes the playbook, stages, roles, record fields and tools for its own industry. It cannot remove the confirmation step, let an agent confirm, or weaken tenant isolation.

Two ways to run it

Self-hosted

Run it in your own data center or cloud, or in your client's. We can help you implement or fork it from the open-source code; you manage and operate it.

Managed Hosting

We help you implement or fork it, and we operate it for you in a multi-tenant environment. United States region planned. No SOC 2 examination has been performed.
